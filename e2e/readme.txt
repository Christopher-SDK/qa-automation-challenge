E2E AUTOMATION – PLAYWRIGHT + CUCUMBER

Este módulo automatiza el flujo de compra exitoso de dos productos
en la web Sauce Demo utilizando Playwright con Cucumber y TypeScript.

Tecnologías:
- Playwright
- Cucumber
- TypeScript
- Page Object Model (POM)

Ejecución:
1. npm install
2. npm run test:e2e
3. node generate-report.js

Resultado:
- Flujo de login
- Agregado de productos
- Checkout completo
- Validación de compra exitosa
